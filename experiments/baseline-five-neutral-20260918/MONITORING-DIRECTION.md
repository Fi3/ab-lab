# User-directed monitoring interval

After the three workflows started, the user instructed: "check every 20 min only".
Manual benchmark checks occur every twenty minutes, superseding the ten-minute
manual interval in the frozen launch protocol. The existing background usage
logger and each workflow's automatic safety limits remain unchanged. This is a
supervising cadence instruction, not a measured prompt or experiment change.
Original protocol, freeze, settings, source and outcomes remain intact.
